# Eminence Client 1.21.11 — Misc

Added to the existing single Fabric project:

- Anti Action — configurable unwanted-action filtering.
- Anti Bot — entity filtering controls.
- Auto Armor — armor selection preferences.
- Auto Pickaxe — mining pickaxe selection.
- Auto Tool — best-tool selection.
- Cart Refill — configurable minecart refill behavior.
- Chest Stealer — configurable chest-transfer behavior.
- Click Friend — click-based friend management.
- Crystal Optimizer — crystal scan/priority settings.
- Fast Place — configurable placement delay.
- Friends — shared friend-state backend.
- Refill — configurable hotbar refill settings.
- Sprint — sprint behavior settings.

The category uses one shared module/settings backend so both GUI layouts can control
the same state. It remains part of the same eventual Fabric JAR.

This package is source code; it has not been runtime-tested in Minecraft 1.21.11 here.
